# SecureStay Real Estates

> **Find a Place. Build a Future.**  
> Curated luxury residences, prime architectural estates, and bespoke property advisory across India's most coveted destinations.

---

## 🏛️ Overview

**SecureStay Real Estates** is an ultra-premium, interactive 3D real estate web platform benchmarked against leading luxury architectural and property auction houses (Sotheby's International Realty, Christie's International Real Estate, Knight Frank).

### ✨ Key Features

- **Interactive 3D Architectural Visualization**: Real-time WebGL/Three.js 3D villa models with camera controls, orbit navigation, and spatial blueprint hotspots.
- **Editorial Typography & Visual Hierarchy**: Elegant pairing of Playfair Display / Cormorant Garamond display serifs with Plus Jakarta Sans body typography.
- **Curated Property Portfolio**: Asymmetric 60/40 lead feature card, dynamic location filters, and comprehensive architectural dossier modals.
- **Strategic Urban Corridors**: Interactive city selector highlighting prime markets across Bengaluru, Mumbai, Goa, Hyderabad, Chennai, and Pune.
- **Bespoke Advisory & Private Inquiries**: Tailored acquisition inquiry desk and institutional headquarters directory.
- **Modern Responsive Design**: Strict 8px spacing rhythm, smooth cubic-bezier scroll reveals, and mobile navigation.

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)

- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconography**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn / pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/richard28_dev/securestay-real-estates.git

# Navigate into directory
cd securestay-real-estates

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be available at `http://localhost:5173/`.

### Production Build

```bash
npm run build
```
